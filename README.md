# LinePacket

Сетевая стратегия в реальном времени для двух сторон: расширяйте сеть, держите связь с ядром, захватывайте машины
соперника и в конце концов захватите его ядро. Против вас играет бот. Godot 4.3, GDScript.

## Запуск

- Из готовой сборки: `build/linux/LinePacket.x86_64` (Linux) или `build/windows/LinePacket.exe` (Windows). Один файл, установки не нужно.
  На Linux при необходимости: `chmod +x LinePacket.x86_64`.
- Из исходников: открыть проект в Godot 4.3 и запустить (F5) или `godot --path .`.

В главном меню выберите сид и сторону, нажмите «Новая игра против бота». Один и тот же сид и сторона дают один и тот же матч.

## Управление

| Действие | Как |
| --- | --- |
| Выделить | рамка ЛКМ по пустому месту (Shift добавляет), клик по своей машине; Esc снимает |
| Назначить роль | перетащить ЛКМ от своей машины (если она выделена вместе с другими, роль получает вся группа) (или ядра) к цели не дальше 3 хопов; роль берётся по текущей клавише |
| Режим роли | Q — захват (INIT) и подбор пароля, W — давление (FLOOD), E — заражение (PAYLOAD), R — тайное заражение, T — дозор (тянуть не нужно, достаточно потянуть от машины) |
| Меню узла (агенты, ПО, роли) | ПКМ по любому узлу; на своей машине — «Роль: Работа / Дозор», на чужой — роли с ближайшей своей машины |
| Скорость игры | − и + (×0.25, ×0.5, ×1, ×2); по умолчанию ×0.5 |
| Выбрать агента | 1, 2, 3 |
| Камера | колесо — только масштаб; средняя кнопка — сдвиг |
| Пауза | Пробел или Esc (Esc сначала снимает выбор) |

Наведите курсор на узел, поток, тип потока в верхней панели, задачу агента или пункт меню — появится подсказка.

Как играть кратко: у каждой своей машины есть роль. «Работа» шлёт DATA в шлюз — это доход. Боевая роль (захват, давление, заражение) шлёт пакеты
на выбранную цель и дохода не даёт; несколько машин на одной цели складываются. Смена роли занимает 5 с, в это время машина молчит.
«Дозор» даёт половину дохода и раз в 10 с обновляет снимки узлов в 2 хопах от машины. Видно только свои узлы и их соседей: остальное узнаётся дозором.
Захват ядра соперника завершает матч. Подробности — в docs/design.md.

## Сборка

```
scripts/export.sh
```

Результат в `build/linux` и `build/windows` (один файл на платформу).
Нужны шаблоны экспорта Godot 4.3.stable. Отладочные клавиши F2 (играть за обе стороны), F3 (панель FPS) и F4 (карта без тумана) работают только в debug-сборке.

## Проверки

```
scripts/test.sh                 # все тесты и проверка детерминизма между процессами
scripts/bot_stats.sh 20 1 40    # 20 матчей бот против бота: победы и длина матча
```

Структура: `sim/` — чистая детерминированная логика, `ai/` — бот (видит только знания своего игрока), `view/` — интерфейс,
`defs/` — числа баланса, `tests/` — тесты, `docs/` — дизайн, план спринтов, журнал.
